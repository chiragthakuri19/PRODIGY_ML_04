# PRODIGY_ML_04: Hand Gesture Recognition

This repository contains a Machine Learning pipeline to identify and classify various hand gestures for human-computer interaction systems.

## Dataset
- Leap Gesture Recognition Dataset (Kaggle) / 3D Hand Landmark Embeddings

## Pipeline Overview
1. **Feature Representation**: Processed 3D coordinate landmark features representing distinct hand gesture postures.
2. **Model Training**: Trained an ensemble **Random Forest Classifier** to accurately classify 10 distinct hand gesture classes.
3. **Evaluation**: Assessed model accuracy, precision, and recall across multi-class gesture outputs.
